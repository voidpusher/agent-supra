# Beta prospect shortlist — 26 October 2026

Thirty public project teams to qualify, not thirty identified or consenting people.
All statuses are **not contacted**. GitHub repository metadata was checked on
26 October 2026; redirects are resolved in the links below. No email addresses,
private profiles or credentials were collected. The fit notes are our inference
from project descriptions, not statements that a team needs or wants Supra.

Start with individual developers in the first ten communities who already run
Python agents or Claude Code. Prefer an explicit invitation to share work or an
existing relationship. Read each project’s current contact/community rules; do
not open promotional bug reports, scrape members, or mass-message maintainers.
Confirm a real workflow with pytest/JUnit or a supported SDK before scheduling.
Large framework organizations are discovery routes, not a substitute for finding
a willing individual tester. No compatibility, response or installation-time claim
has been verified for any candidate.

## Qualification and contact record

Keep recipient contact details in an ignored private worksheet, not this public file.
For each candidate record: preferred permitted contact route; named consenting
tester; OS/Python/Claude version; integration; actual task; whether they already
know the founder; permission to contact; last contact; response; session time.
Send only individually reviewed messages after the owner authorizes recipients.

Success is a real agent run with received test evidence, then reviewed flags.
A message sent, repository owner, signup, empty run or internal fixture is not an
activated outside user. Avoid duplicate invitations to the three earlier recipients.
