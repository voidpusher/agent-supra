Privacy

What {{ app_name }} stores, why, and how to delete it.

What the SDK sends

  • Model name and token counts for each model call.
  • Test IDs and which ones failed, plus a code revision ID you choose (for example a git hash).
  • Tool names, whether they succeeded, and fingerprints of their arguments and errors. A fingerprint is a keyed hash: it shows two errors were the same without revealing what they said.
  • Task names you give each task, and an optional outcome.

What it never sends

Your prompts, the model's replies, your source code, file contents, or your model provider API keys. Your agent calls the model provider directly.

What we store about you

Your email address and a scrypt hash of your password. API keys and login sessions are stored only as SHA-256 hashes, so they can't be read back out of the database.

How long it's kept

Run data is deleted after {{ retention_days }} days. Account details stay until you delete your account.

Deleting your data

Settings, then Delete account, removes your workspace, every run and event, your API keys and your login immediately.

Who processes it

Data is stored with this service's hosting and database provider. Alerts go only to the Slack webhook and email address you set.
