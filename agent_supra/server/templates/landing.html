01 / HOW IT WORKS

Know when progress stops.

Track results across attempts. Start with observation, then enable pauses when you're ready.

  1. Install

    pip install agent-supra
    Works with Gemini, OpenAI and Anthropic.

  2. Connect

    Wrap your model client and report test results from your agent's loop.

  3. Stay informed

    Review evidence in your dashboard. Get alerts in Slack or email.

02 / SIGNALS

What it watches for

Readable rules. Choose which ones flag, pause, or stay off.

No progress

The same tests keep failing while the agent keeps changing the code.

Exact repeats

The same failure again with nothing changed, or the same tool failing the same way.

Going in circles

The agent flips between two versions of the code.

Context running away

Every call sends more tokens than the last, with nothing to show for it.

Budget and call caps

A hard limit per task, shared with any sub-agents it starts.

03 / INTEGRATION

Fits your existing agent.

Use your own model client and API keys.

View a Gemini example +
from google import genai
from agent_supra import (
    Client, SupervisedRun, SupervisorPaused)

sup = Client()   # reads your API key from env
task = sup.create_task("Fix checkout tests",
                       budget_usd=3)

with SupervisedRun(sup, task) as run:
    ai = run.wrap_gemini(genai.Client())
    try:
        while True:
            run.check()
            reply = ai.models.generate_content(
                model="gemini-3.5-flash-lite",
                contents=prompt)
            apply_fix(reply.text)
            t = run_tests()
            run.report_tests(t.all, t.failing,
                             rev=git_rev())
            if not t.failing:
                run.finish("success")
                break
    except SupervisorPaused as paused:
        print(paused.reason)

04 / BEFORE YOU START

A few good questions.

Will it stop my agent automatically?+

Start in observation mode to record signals while your agent continues. Enable pause rules when you're ready; the SDK then pauses the next supervised step.

Do I need to change model providers?+

No. Keep your Gemini, OpenAI or Anthropic client and your own API keys. Add Agent Supra to your existing loop.

Does it store my prompts or code?+

It records test results, token counts and fingerprints. Prompts, code and model replies are not stored. Read the privacy details.

What does it cost?+

Agent Supra is free during beta. You pay your model provider separately for model usage.
